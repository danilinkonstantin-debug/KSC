# Инжиниринговый центр КНЦ РАН

Сайт: https://danilinkonstantin-debug.github.io/KSC/

Редакция от 16 октября 2026 года. В репозитории — готовая статическая сборка для GitHub Pages с базовым путём `/KSC/`. Публикация выполняется автоматически из ветки `main`, корневая папка.

Сохранено прежнее оформление. На сайте 48 услуг в семи направлениях, 17 примеров работ и 12 позиций испытательной базы с отдельными страницами. Новые химические модули и экологические установки обозначены как программа оснащения без непроверенного заявления об их запуске.

Состав и изображения оборудования сверены с презентацией ИЦ для БАЭП от 20.11.2025, официальными публикациями КНЦ РАН от 06.05.2026 и 16.09.2026 и каталогом ЦКП ИХТРЭМС. Фотографии и иллюстрации подписаны. Зарубежные объекты не представлены как оборудование КНЦ РАН. Сведения об аккредитации привязаны к конкретным лабораториям и датированным источникам; текущие записи недоступных реестров не объявлены проверенными.

Форма по кнопке в шапке подготавливает текст обращения для копирования, скачивания или открытия в почтовой программе. Автоматическая отправка пока не подключена. Плавающих блоков обратной связи нет.

`assets/site.css` и `assets/prototype.css` задают исходное оформление, `assets/editorial.css` — новые разделы. `assets/site.js` обслуживает каталог и форму, `assets/editorial.js` — фильтры кейсов и оборудования. Для локального просмотра нужен статический сервер с размещением этой папки по пути `/KSC/`; абсолютные пути рассчитаны на GitHub Pages.

Прототип общедоступен, но содержит запрет поисковой индексации. При публичном SEO-запуске потребуется отдельно настроить индексирование и обработку обращений.
