# Инжиниринговый центр КНЦ РАН

Рабочий интерактивный прототип: https://danilinkonstantin-debug.github.io/KSC/

Редакция от 16 октября 2026 года. Семь направлений услуг, 48 страниц услуг, поиск по каталогу, фильтры и выбор нескольких услуг в программу работ. ТЭО, комплексная экономическая оценка и исследования рынков минерального сырья и продуктов выделены в направлении «Экономика и маркетинг».

Переход к форме обращения находится в верхней панели. Форма подготавливает текст для копирования, скачивания или открытия в почтовой программе; автоматическая отправка не подключена. Выбор услуг хранится в браузере, персональные сведения формы автоматически не сохраняются.

## Публикация

GitHub Pages публикует готовые файлы из корня ветки main. Файл .nojekyll отключает обработку Jekyll. Внутренние пути и загрузка каталога настроены на базовый путь /KSC/.

## Файлы

Тексты страниц находятся в index.html в соответствующих папках. Каталог для поиска и формы — assets/catalog.json, логика — assets/site.js, стили — assets/site.css и assets/prototype.css. Изображения и шрифты хранятся локально в assets/.

Для локальной проверки требуется HTTP-сервер с сайтом по пути /KSC/: загрузка каталога использует fetch. Все 27 прежних адресов услуг перенаправляют в новую структуру.

## Статус

Ссылки, якоря, структура каталога и интерактивная логика проверены. Визуальная браузерная проверка адаптивности не выполнена. Индексирование прототипа отключено метатегами noindex, nofollow; GitHub Pages и репозиторий общедоступны.
