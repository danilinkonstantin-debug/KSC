# Инжиниринговый центр ФИЦ КНЦ РАН

Статический прототип сайта, подготовленный для GitHub Pages. Содержимое соответствует редакции от 19 сентября 2026 года. Все изображения, шрифты, стили и сценарии находятся в репозитории.

## Включение GitHub Pages

1. Откройте **Settings → Pages** в репозитории KSC.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. Дождитесь успешной публикации. Планируемый адрес: https://danilinkonstantin-debug.github.io/KSC/

После включения Pages изменения файлов в ветке main будут автоматически публиковаться. Файл .nojekyll отключает обработку Jekyll: GitHub размещает готовые файлы сайта.

## Локальное редактирование

Скачайте репозиторий через **Code → Download ZIP**, распакуйте целиком и откройте index.html в Chrome, Edge или Firefox. Для обычного просмотра сервер и установка зависимостей не требуются.

Тексты находятся в index.html и в файлах index.html в папках страниц. Оформление задаётся в assets/site.css; изображения и шрифты находятся в assets/. Навигация и формирование текста обращения реализованы в assets/site.js. Сохраняйте структуру папок и относительные пути. Публичная страница 404.html использует базовый путь /KSC/ для корректной работы при неизвестных адресах.

## Статус прототипа

Форма подготавливает текст обращения для копирования или скачивания и не отправляет его получателю. Для приёма заявок необходимо подключить обработчик.

В HTML сохранён noindex, nofollow. Это просьба поисковым системам не индексировать прототип, а не ограничение доступа: репозиторий и опубликованный GitHub Pages сайт общедоступны. Перед SEO-запуском нужно утвердить основной адрес, проверить canonical и структурированные данные, настроить индексирование, Sitemap и приём обращений.
