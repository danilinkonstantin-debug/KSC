Исследование шлака для получения строительных материалов

Работы выполнены

Задача

Охарактеризовать металлургический шлак и оценить возможности его использования в строительных материалах.

Выполненные работы

  • Исследование характеристик металлургического шлака.
  • Разработка рекомендаций по применению шлака для получения строительно-технических материалов.

Результат

Получены характеристики шлака и разработаны рекомендации по его использованию в строительных материалах.
