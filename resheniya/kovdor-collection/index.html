Задача

Подготовить петрографические материалы для эталонной коллекции Ковдорского месторождения.

Выполненные работы

  • Подготовка шлифов по материалам участка «Гора Южная».
  • Петрографическое описание подготовленных шлифов.

Результат

Подготовлены шлифы и их описания для эталонной коллекции участка «Гора Южная» Ковдорского месторождения.
